# 🎓 School Management System

A desktop application built in Java to help administrators manage school operations efficiently. 

## 🚀 Features
* **Secure Authentication:** Cloud-connected admin login system.
* **Cloud Database:** Real-time data storage powered by Aiven (MySQL).
* **Dashboard Management:** (Add features here as you build them, like Student Tracking, Attendance, etc.)

## 💻 Tech Stack
* **Language:** Java
* **UI Framework:** Java Swing
* **Database:** MySQL (Aiven Cloud)
* **IDE:** Apache NetBeans

## 🛠️ How to Run
1. Ensure you have **Java 17 or higher** installed on your system.
2. Download the `dist` folder from this repository.
3. Open your terminal or command prompt in that folder.
4. Run the following command:
   `java -jar SchoolManagement.jar`
5. Login with the default credentials:
   * **Username:** admin
   * **Password:** 123
